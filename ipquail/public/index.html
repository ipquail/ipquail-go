This website can also be shell scripted using curl:

$IP6 = Invoke-RestMethod 'https://6.ipquail.com/ip'
$IP4 = Invoke-RestMethod 'https://4.ipquail.com/ip'
$PTR6 = Invoke-RestMethod 'https://6.ipquail.com/ptr'
